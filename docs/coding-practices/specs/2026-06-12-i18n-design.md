# i18n 国际化系统设计文档

> 日期：2026-06-12 | 模块：核心能力 | 优先级：P1

## 概述

为 ZC UI 组件库实现轻量级 i18n（国际化）系统。支持中英文切换、命名参数插值、用户自定义语言包扩展，以及 Vue 3 响应式语言切换。

## 需求摘要

1. locale 多语言字典结构设计（zh-CN 默认、en-US）
2. `t(key)` 翻译函数实现
3. `useLocale` composable（响应式语言切换）
4. 全局语言配置注入（`app.provide`）
5. 组件内通过 `inject` 获取翻译文案的模式
6. 用户自定义语言包的扩展接口

**验收标准**：组件文案可通过配置切换中英文，支持用户传入自定义语言包。

## 架构方案：全局响应式 Store + provide/inject 层

模块级响应式单例存储 locale 状态，`t()` 直接读取全局 ref，`useLocale()` 返回绑定到全局状态的 composable，插件通过 `app.provide` 暴露注入 key。

### 与现有代码的一致性

- 与 `useZIndex` 模式一致：模块级共享 `ref` + composable 返回 computed
- `t()` 在组件内外都能用（工具函数、非 setup 代码均可调用）
- `provide/inject` 让组件能响应式获取翻译

## 类型系统

```ts
/** 语言代码类型，默认内置 zh-CN / en-US，但用户可注册任意语言 */
type Language = string

/** 翻译字典值：字符串或嵌套对象 */
type LocaleDictionary = Record<string, string | LocaleDictionary>

/** 命名参数插值的参数类型 */
type TranslateOptions = Record<string, string | number>
```

### 字典结构规则

- 用户可传嵌套对象：`{ button: { confirm: '确定' } }`
- 内部递归拍平为：`{ 'button.confirm': '确定' }`
- 存储统一用扁平结构，查询效率 O(1)
- 如果用户直接传扁平 key（`{ 'button.confirm': '确定' }`），也正常工作

### 插值规则

- 模板中用 `{name}` 占位：`'welcome': '欢迎, {name}'`
- `t('welcome', { name: '张三' })` → `'欢迎, 张三'`
- 未提供的占位符保持原样

## 文件结构

将 `packages/locale/src/index.ts` 拆分为：

| 文件            | 职责                                        |
| --------------- | ------------------------------------------- |
| `dictionary.ts` | 嵌套对象拍平工具函数 `flatten()`            |
| `translate.ts`  | 插值工具函数 `interpolate()`                |
| `create.ts`     | locale store 创建逻辑 + `createLocale` 插件 |
| `index.ts`      | 统一导出 + 模块级默认实例 + 内置消息字典    |

## 核心 API

### 模块级单例状态

```ts
const _localeRef = ref<Language>('zh-CN')
const _messages = reactive<Record<Language, Record<string, string>>>({
  'zh-CN': {
    /* 扁平化后的内置中文 */
  },
  'en-US': {
    /* 扁平化后的内置英文 */
  },
})
```

### t() 翻译函数

```ts
function t(key: string, options?: TranslateOptions): string
```

1. 从 `_messages[_localeRef.value]` 查找 key
2. 未找到则回退到 key 本身
3. 如果有 options，进行 `{name}` → value 插值

### setLocale / getLocale

```ts
function setLocale(lang: Language): void // 设置当前语言（响应式）
function getLocale(): Language // 获取当前语言
```

### register 扩展接口

```ts
function register(lang: Language, dict: LocaleDictionary): void
```

将嵌套 dict 拍平后合并到 `_messages[lang]`。如果 lang 不存在则创建。用户可注册全新语言（如 ja-JP）或覆盖已有 key。

### 内置消息字典

| Key              | zh-CN     | en-US      |
| ---------------- | --------- | ---------- |
| `common.confirm` | 确定      | Confirm    |
| `common.cancel`  | 取消      | Cancel     |
| `common.loading` | 加载中... | Loading... |
| `common.empty`   | 暂无数据  | No data    |
| `common.ok`      | 确定      | OK         |
| `common.save`    | 保存      | Save       |
| `common.delete`  | 删除      | Delete     |
| `common.close`   | 关闭      | Close      |

## useLocale composable

```ts
export const localeInjectionKey: InjectionKey<LocaleContext> = Symbol('zcLocale')

interface LocaleContext {
  locale: Readonly<Ref<Language>>
  t: typeof t
  setLocale: typeof setLocale
  getLocale: typeof getLocale
  register: typeof register
}

export function useLocale(): LocaleContext
```

组件内使用时优先 `inject` 注入实例；无注入时回退到全局单例（非组件上下文也可用）。

### createLocale 插件

```ts
export function createLocale(options?: {
  locale?: Language
  messages?: Record<Language, LocaleDictionary>
}): Plugin
```

安装时执行 `app.provide(localeInjectionKey, ctx)`，让所有子组件可通过 `useLocale()` 获取注入的 locale 上下文。

## 组件中使用模式

```vue
<script setup lang="ts">
import { useLocale } from '@zc-ui/locale'
const { t, locale, setLocale } = useLocale()
// t('common.confirm') → '确定' / 'Confirm'
// setLocale('en-US') → 响应式切换，模板自动更新
</script>
```

## 测试策略

在 `packages/locale/src/__tests__/` 下创建：

| 测试文件             | 覆盖内容                                                                        |
| -------------------- | ------------------------------------------------------------------------------- |
| `dictionary.spec.ts` | 嵌套拍平、多层嵌套、空对象、已有扁平 key                                        |
| `translate.spec.ts`  | `{name}` 插值、多参数、未提供占位符保持原样                                     |
| `index.spec.ts`      | `t()` 查找/回退、`setLocale/getLocale`、`register`、`useLocale`、`createLocale` |

关键场景：

- 切换语言后 `t()` 返回对应语言文案
- 未注册的 key 返回 key 本身
- `register('ja-JP', {...})` 后可用
- `register` 覆盖已有 key 不影响其他 key
- `t('welcome', { name })` 正确插值
- `useLocale()` 在 provide 上下文中返回注入实例
- `useLocale()` 在无 provide 时回退到全局单例

需在 `vitest.config.ts` 的 `resolve.alias` 中添加 `@zc-ui/locale` 路径映射。
