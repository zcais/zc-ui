# 组件总览

ZC UI 是一个基于 Vue 3 + TypeScript 的企业级 UI 组件库，提供 **90+ 高质量组件**，覆盖布局、表单、数据展示、反馈、导航等常见业务场景。

## 特性

- 🎯 **Vue 3 Composition API** - 全面采用 `<script setup>` 语法
- 📦 **TypeScript** - 完整类型定义，类型安全
- 🎨 **设计 Token 系统** - 基于 CSS 自定义属性的主题方案
- 🔧 **按需引入** - 支持 tree-shaking，减小打包体积
- 🌍 **国际化** - 内置 i18n 支持
- ♿ **无障碍** - 支持 ARIA 标准和键盘导航
