## 3.0.0-rc.1

### Major Changes

- # 🎉 首次发布：ZC UI 1.0.0

  ZC UI 是一套基于 Vue 3 + TypeScript 的企业级 UI 组件库。本次发布包含 7 个核心包：

  - `@zc-ui/components` — 80+ Vue 3 组件
  - `@zc-ui/hooks` — Vue 3 组合式函数
  - `@zc-ui/utils` — 通用工具函数
  - `@zc-ui/theme` — 主题与设计变量
  - `@zc-ui/locale` — 国际化 (i18n)
  - `@zc-ui/resolver` — unplugin-vue-components / unplugin-auto-import 的 resolver
  - `@zc-ui/nuxt` — Nuxt 3 模块

  ## ✨ 特性
  - ✅ Vue 3 Composition API + `<script setup>` 全面支持
  - ✅ 严格的 TypeScript 类型定义
  - ✅ 基于 CSS 变量的主题系统，支持亮色 / 暗色 / 自定义主题
  - ✅ ESM + CJS 双格式，按需引入 + Tree Shaking 友好
  - ✅ SSR 友好

  ## 📦 安装

  ```bash
  npm install @zc-ui/components
  ```

  完整使用文档请参考 [在线文档](https://zcais.github.io/zc-ui/)。

### Patch Changes

- Updated dependencies
  - @zc-ui/locale@3.0.0-rc.1
  - @zc-ui/utils@3.0.0-rc.1
